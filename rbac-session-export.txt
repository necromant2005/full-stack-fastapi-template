  - create the account with `role=admin`;
  - hash the temporary password;
  - set `must_change_password=true`.
- If the bootstrap email belongs to an existing non-admin user, fail with a clear error rather than silently elevating it.

- Restarting the application must never reset an existing password or reapply the temporary password.
